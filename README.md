# Activity Recorder


A lightweight and intuitive desktop application designed to record and automate mouse movements, clicks, and keyboard strokes. Easily record repetitive tasks and play them back with exact precision.

## Features

* **Complete Action Recording**: Records mouse movement, precise cursor positions, clicks, and keyboard shortcuts/keypresses.
* **Exact Playback**: Reproduces recorded user actions with exact timing and spatial accuracy.
* **Global Hotkeys**: Control recording and playback effortlessly using quick keyboard shortcuts even when the app is in the background.


* **Minimalist UI**: Simple, clean four-button interface for friction-free usage.



---

##  Default Hotkeys

| Action | Hotkey | Description |
| --- | --- | --- |
| **Record** | `Ctrl + F7` | Starts recording user inputs.
| **Stop** | `Ctrl + F8` | Stops recording or playback.
| **Play** | `Ctrl + F9` | Replays the recorded actions.

##  Usage

1. Launch **Activity Recorder**.


2. Press **`Ctrl + F7`** (or click **Record**) to start recording your actions.


3. Perform the repetitive sequence of clicks and keypresses on your desktop.
4. Press **`Ctrl + F8`** (or click **Stop**) to finalize the recording.


5. Press **`Ctrl + F9`** (or click **Play**) to execute the recorded actions automatically.





## Configuration & Settings

The **Settings** menu allows you to fully customize how actions are recorded, replayed, and how the app behaves:

### Record Options
Toggle specific input types to record only what you need:
* **Keyboard**: Enable or disable recording of keystrokes.
* **Mouse Move**: Enable or disable tracking cursor movement.
* **Mouse Clicks**: Enable or disable recording left, right, or middle mouse clicks.

### Playback Options
* **Loop**: Enable continuous looping of recorded actions during playback.

### Behavior Options
* **Minimize to System Tray**: Keeps the app running quietly in the system tray when minimized.
* **Minimize on Play / Record**: Automatically minimizes the window when starting recording or playback to avoid blocking the screen.
* **Show Status Overlay**: Displays an on-screen overlay indicating current status (Recording/Playing).
* **Always on Top**: Keeps the app window above all other open windows.
* **Turn Off All Events at [HH:MM]**: Schedule a specific time to automatically stop recording or playback activities.

### Window & Interface
* **Window Title**: Customize the main window title bar text (default: `Activity Recorder`).
